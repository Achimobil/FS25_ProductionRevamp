# FS25_ProductionRevamp

![Status](https://img.shields.io/badge/status-released-4CAF50)
![Platform](https://img.shields.io/badge/Farming%20Simulator-25-4CAF50)
![License](https://img.shields.io/badge/license-custom-lightgrey)

**Production Revamp** war ursprünglich ein Projekt von **Braeven (Micha)** für den Farming Simulator 22.
Micha hat sich 2026 aus dem Modding zurückgezogen und **Achimobil** ausdrücklich die Erlaubnis gegeben,
seinen bestehenden Code zu übernehmen, anzupassen, auf den Farming Simulator 25 zu übertragen und den
daraus entstehenden Mod auch über das GIANTS-Programm zu vertreiben. Einzige Bedingung war eine
Namensnennung im Code.

Dieses Repository führt Michas bereits begonnenen FS25-Port fort und wird von **Achimobil**
weiterentwickelt.

## Entwicklungs-Setup

![VS Code](https://img.shields.io/badge/VS%20Code-007ACC?logo=visualstudiocode&logoColor=white)
![GIANTS Plugin](https://img.shields.io/badge/GIANTS-Editor%20Plugin-1a1a1a)
![Claude Code](https://img.shields.io/badge/Claude%20Code-AI%20Pair%20Programming-6B4FBB)

Planung und Umsetzung erfolgen in **Visual Studio Code** mit dem **GIANTS-Plugin** für das
Luau-Scripting, unterstützt durch **Claude Code** als KI-Werkzeug für Analyse, Planung und
Implementierung.
